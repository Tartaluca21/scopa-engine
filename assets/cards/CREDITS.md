## File mapping

Each `<value>_<suit>.png` here is byte-identical (verified by SHA-1) to the
correspondingly numbered Commons file:

- `<value>_denari.png` → `File:01 Asso di denari.jpg` … `File:10 Dieci di denari.jpg`
- `<value>_coppe.png`  → `File:11 Asso di coppe.jpg`  … `File:20 Dieci di coppe.jpg`
- `<value>_spade.png`  → `File:21 Asso di spade.jpg`  … `File:30 Dieci di spade.jpg`
- `<value>_bastoni.png`→ `File:31 Asso di bastoni.jpg`… `File:40 Dieci di Bastoni.jpg`
- `back.png`           → `File:Carte Napoletane retro.jpg`

(The files keep a `.png` extension but are JPEG data, exactly as distributed on
Commons.)

## Verification

The license of each individual file was confirmed via the Wikimedia Commons
`imageinfo` API (`extmetadata.LicenseShortName = "Public domain"` for all 41
files), not from the category page footer (whose CC0/CC BY-SA notice covers only
structured data and page text, never the media). Byte-identity between these
files and the Public-Domain Commons originals was confirmed by SHA-1.
